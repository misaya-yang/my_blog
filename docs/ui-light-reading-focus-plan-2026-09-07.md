# 浅色星系、阅读联动与焦点优化

## 范围与设计约束

保留已经认可的立体星系构图、自动运动、360 度拖动、鼠标响应和滚动分散/聚合。公共页面默认保持开放背景，悬浮时才显示区域边界；当前项、键盘焦点与悬浮必须可区分。文章内容与数学字体不改写，不增加粒子开关或依赖。

## 执行计划及结果

### 1. 浅色光学表现 — 已完成

- 原因：白色星芯与深色晕圈形成水渍感，1600 个深色体积片累积成灰雾。
- 改动：浅色星点使用有色实心星核，保留蓝色与少量暖色；收紧星核，降低细碎尘点不透明度，体积层使用浅蓝颜色连接星流。深色发光方式保留。
- 验收：首页同类视口对比灰晕、星核与层次；阅读页不出现大光斑穿透文字；拖动与复位仍工作。

### 2. 正文与目录双向联动 — 已完成

- 原因一：旧 IntersectionObserver 只处理当前一批进出事件，不能稳定识别长段落与快速跳过的小节。
- 原因二：正文 Markdown 延迟加载，目录监听开始时标题可能尚不存在，原实现没有补绑定。
- 原因三：文档 scroll-padding 92px 与标题 scroll-margin 100px 叠加，点击标题停在 192px，而阅读判断线在其上方，导致目录仍选中前一节。
- 改动：缓存标题文档坐标，使用被动滚动监听与 RAF 批处理、二分查找当前小节；监听正文挂载、字体和尺寸变化。目录通过 aria-current 声明选中项，只滚动自己的容器保持其可见。统一锚点偏移，处理刷新与 hashchange。手机目录同步选中、点击后折叠；键盘跳转把焦点交给正文标题。
- 验收：强化学习长文实测 3.2/3.7 等章节；快速向下与向上滚动；点击 3.7 后正文标题约 112px，目录同步选中 3.7；刷新保留定位；手机点击 2.2 后折叠且选中一致。

- 额外修复：正文组件 memo 化，目录更新不再重建标题和公式，避免键盘焦点刚到标题就丢失。

### 3. 悬浮、当前项与键盘焦点 — 已完成

- 默认：公共内容表面透明；常用输入保留单层外壳。
- Hover：叶级面板和文章/搜索行显示 1px 清晰边界；即使旧样式边框宽度为零，也有不改变布局的内侧轮廓。
- Current：目录持续显示主题底色、左侧标记和更高字重。
- Keyboard：焦点使用独立 2px 主题轮廓；与 hover 的灰蓝边界不同。搜索输入由外壳负责焦点，不增加第二个框。
- Touch：手机目录保留可发现的展开入口和选中态，不依赖 hover。
- 验收：内置浏览器测得浅色焦点 #087c9d / 2px；深色 hover #546776 / 1px；搜索行 hover 生效，外层结果容器仍透明。

### 4. 布局、字体与动效衔接 — 已完成

- 目录标题在独立滚动区内保持可见；手机展开目录限制高度，避免占用整个长文。
- 正文仍使用 Source Sans 3 与明确的中文无衬线回退，数学公式保留 KaTeX 字体。
- 修正粒子避让：从顶点插值改成逐屏幕像素计算，防止近处大星点把边缘亮度插值到正文。没有增加渲染通道。
- 320px 与 390px 阅读页无横向溢出；长公式在自己的容器内横向滚动。

## 验证范围

内置浏览器：1440×900、1280×800、390×844、320×740；长文章、浅色首页、深色阅读、搜索结果。实测目录滚动、点击/刷新/反向滚动、Tab 焦点、手机展开折叠、输入外壳焦点、结果行 hover、星系拖动复位及滚动衔接。

相关单元测试覆盖长章节间隔、快速正反向移动、边界位置，以及既有星系数学和 Markdown 渲染。TypeScript、相关 10 项测试、生产构建与 git diff --check 均已通过。完整重载后，键盘跳转至 2.5 节的焦点仍在 H3，轮廓为 #087c9d / 2px，目录选中一致。

源码扫描 0 FAIL、2 WARN：输入去轮廓由单层外壳焦点替代；滚动监听被动、由 RAF 合并且在卸载时清理。使用内置浏览器进行交互检查，没有运行会另开外部浏览器的 audit-page.mjs。未测 CPU 限速/低端设备帧率，不宣称性能指标通过。WebGL 失败时的旧静态后备素材仍未更换。
