# 粒子滚动复查与本轮实现

本记录覆盖此前报告中“限幅旋转、短时播放、独立右侧画布、单张通用封面”的实现建议。当前用户接受的是整屏立体星场；M、光环、内容寓意和额外空白聚合屏已弃用。

## 官网现场证据

参考：https://openai.com/index/gpt-6-astra/ 。本轮在内置浏览器观察了聚合区、分散区、前后滚动，读取了实际 Canvas 的 DOM 样式。

- 官网分散后仍是覆盖整个视口的疏密星场，并非将左右两半压缩成两条边栏。
- Canvas 固定覆盖视口。1440 × 900 视口下，观测到横向渐变遮罩：两侧不透明，正文区域透明度随状态变化；本轮读到过 0.35 和约 0.663。
- 滚动进入光标形态的区间，画面从松散星场收拢；离开后仍保持背景运动。仅凭这些画面不能确定它使用哪一种物理模拟、粒子数量或着色器算法。
- 对页面公开加载脚本的外部下载请求返回 HTTP 403，因此没有把“官网使用某个流场或弹簧实现”作为已确认事实。

## 本项目的改动

- 一套固定视口的 Three.js 场景贯穿首页。保留自动运动、四元数轨迹球、惯性旋转、局部鼠标响应与实例化拖尾。
- 原来的左右压缩平移已换成逐粒子的确定性分散目标：不同启动进度、弯曲中间路径、前后景深度、缓慢漂移。反向滚动沿同一映射恢复。
- 拖尾采样较早的滚动状态，不只是随着整体平移的装饰线。限制近裁切面附近的分散深度，避免星点突然放大或穿越相机。
- 通过渐变衰减保护正文，而不是强行清空整块画面。桌面端在已有“研究方向”内容旁重新聚合，不增加专用空屏；手机保留紧凑阅读与持续分散背景，不强行塞入该二次聚合场景。
- 取消过长的首屏固定滚动区，标题随正常文档流离开，文章及时进入。
- 首页通用 JPG 封面不再占据主体。接入真实公开文章列表，提供六篇可切换的标题、摘要、日期与正文小节预览，其余文章继续在下方展示。移动端切换后滚回对应预览。
- 面板采用稳定圆角，两种主题都有对应表面色；默认、悬浮、焦点状态不再切换方圆形状。Source Sans 3 本地加载，中文使用明确的无衬线回退。

## 验证及边界

- TypeScript 检查、生产构建、轨迹球与滚动阶段的四项数学/边界测试通过。数学测试不是浏览器动效质量证明。
- 内置浏览器检查了桌面深浅主题、连续滚动、反向恢复、正文区域聚合、拖拽、文章预览切换，以及 390 × 844 手机浅色排版与切换。手机无横向溢出，刷新后只有一个 Canvas。
- 源码扫描：0 个失败、3 个警告。画布焦点由可见键盘说明替代；scroll 监听被动且由 RAF 合并、卸载清理；汉字标题有独立字距覆盖。警告经过逐项判断，未记为自动通过。
- 没有通过 CLI 启动额外浏览器，未运行该技能的 Playwright 页面审计脚本；使用用户指定的内置浏览器走查。未做低端实体设备或 CPU 限速下的持续帧率、INP 测量，不据此宣称稳定 60 FPS。
- WebGL 失败时仍保留旧静态后备图；减少动态效果会绘制当前场景的静止帧。新的静态后备美术尚未替换。
- 未提交、推送或部署。


## 布局协调补充

在用户认可粒子效果后，本轮只调整 Home 与首页样式，不改粒子渲染算法。导航、首屏、内容和页脚共用对齐线；近期文章改为一个带目录与预览的阅读面板，下方列表使用同样的阅读背景，星场保留在边缘和研究方向区域。去掉列表旧负边距与页脚重复文案，正文小节改用无重复编号的列表。

内置浏览器走查了 1280、768、390 像素宽度。桌面采用左右目录/预览，平板采用上下预览和双列目录，手机单列；窄屏切换文章后滚回预览。深浅主题、文章切换、横向溢出和当前渲染日志均已检查。源码检查无失败，既有焦点替代与中文字距警告的判断不变。没有为此次低风险布局修改新增测试文件。

## 公共页面与开放表面（最终补充）

此节覆盖上文仅首页、实体阅读面板的旧范围与外观描述。

- 将 GalaxyHero 提升到公共路由层，首页、文章、搜索、分类、归档和作者页共享一个渲染器。内置浏览器通过 Canvas 的实例标识验证 SPA 跳转没有重建实例。
- 文章路径生成稳定种子，控制分布角度、倾斜与漂移速度；不同文章有不同组合，查询参数和锚点不改变组合。作者页单独构图，以 misaya 字标呈现姓名；修复联系栏与关注区重叠。
- 公共面板默认透明、无固定边框和阴影；叶级行/面板只在悬浮或焦点进入时出现轻边界，圆角和尺寸保持稳定。搜索输入与提交按钮合并为单层外壳，键盘焦点也由外壳统一呈现。
- 渲染器按可见正文与目录的 DOM 边界进行柔和粒子衰减，保留连续背景，避免用不透明黑色大面板遮挡星场。星点采用蓝、蓝白、白和暖琥珀色，减少亮核向纯白混合的比例。
- 统一文章、分类、归档、搜索的内容宽度与窄屏布局；目录保留一个滚动容器，取消重复内部滚动条与多余分隔线。

验证：TypeScript 检查与生产构建通过；星场辅助模块 3 个测试文件、6 项测试通过。浏览器观察到两篇文章的不同稳定变体及同一 Canvas 实例，检查了深浅主题、搜索单层焦点与悬浮边界、文章目录定位、作者页桌面/手机布局。最终源码扫描 0 失败、2 警告，分别为由外壳替代的输入焦点样式和既有被动 RAF 滚动处理。未做实体低端设备帧率测量，未提交或部署。

### 代码块阅读细节

移除 pre 与 highlight.js 双层底色、双层内边距。代码块现在由单层主题表面、独立语言/复制工具栏和唯一横向滚动区组成，复制按钮不覆盖源码。高亮颜色区分深浅主题，代码区可用键盘获取焦点及横向滚动。390 像素内置浏览器验证页面无横向溢出、代码自身 scrollLeft 可变化；桌面浅色验证复制成功图标与提示。Markdown 与星场测试共 4 文件、8 项通过，TypeScript 检查通过。
