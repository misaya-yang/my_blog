# UI 升级实施与验收记录

日期：2026-09-07。范围：当前项目的本地代码及浏览器验收；尚未提交、推送或部署。

## 最终设计方向

沿用前两份报告的内容结构，并落实本轮修正：以个人研究站身份取代通用 AI 产品口号；首屏显示 Misaya Notes；减弱蓝色装饰、编号与按钮式宣传。原创粒子星系是首屏主视觉，正文保持安静。属于受 Astra 启发的原创改版，不声称逐像素复刻官网。生成的初稿已经被用户否定，不是最终验收参考。

- 首页：身份与主视觉 → 精选文章 → 算法 / 应用方向 → 最近文章 → 作者入口。搜索保留在导航中。
- 字体：已有自托管 Instrument Sans 承担显示和界面，利用开放字腔、低笔画对比和可变字重形成研究仪器般的清晰感；显示标题用 450 字重、明显尺度差，避免整页粗体。中文明确使用黑体回退栈，正文 17–18px，独立行高与非负字距。代码保留 JetBrains Mono。
- 光学修订：两个主题的首屏均采用深空底色与真实发光星群；浅色主题的导航、正文和其余内容仍为浅色。已撤下灰色点云方向。亮星、冷暖星点与远景星尘独立控制，不再通过统一的小点精灵表现全部层次。
- 取消星系播放／暂停开关。自动姿态变化最多约 4.2 秒后停稳，后续由鼠标与滚动输入驱动。无滚动劫持或强制多屏停留。
- 分类路径默认折叠，文章列表提前出现；搜索、归档与关于页同步收敛背景、边框和间距。

## 实现

主要入口：`client/src/styles/observatory.css`、`client/src/pages/Home.tsx`、`client/src/components/galaxy/`。

Three.js r180 + Points 星尘 + InstancedBufferGeometry / Mesh 亮星面片 + ShaderMaterial。没有引入第二个 React 动效框架、GSAP 或平滑滚动库。Three.js 的独立场景分块仅在首页、且未请求减少动态效果时加载。该新增分块构建后约 119KB gzip。

光学修订后的常规场景包含 5,200 个细星点和 520 个恒星面片；小尺寸场景为 3,200 个细星点和 350 个恒星面片。DPR 分别封顶 1.5 / 1.25，尺寸变化时同步调整。亮星使用朝向相机的实例化四边形，避免 GPU 点精灵尺寸上限裁掉光晕。着色器分别计算白色星核、近光晕和宽光晕，并保留蓝色与暖橙色星点。

几何一次生成，运行期间更新统一参数；离屏、页面隐藏时停止绘制；静止后不保留空转 RAF。卸载释放两套几何、材质、渲染器、事件与观察器。主题切换保持同一光学场景，不再重建一套反色星云。

当前静态后备为 `client/public/images/galaxy-poster.png`，约 307KB，来自本地实际 WebGL 渲染。内置浏览器的裁剪输出曾包含非目标页面区域，检查发现后弃用该输出，改用项目已有 Playwright 对星系元素导出，并通过 view_image 检查画面内没有文字或 UI。减少动态效果不加载 WebGL；初始化失败、场景分块加载失败或 context lost 时显示此图。之前的两张 SVG 已不再被页面引用。


阅读修复：

- 在 Markdown 解释之前，将标准 LaTeX 的 `\[...\]` / `\(...\)` 转换为数学插件接受的分隔符；代码围栏和行内代码保持原样。
- 修复被独立等号误解释成 H1 的公式，恢复正常数学结构。
- 由目录外层承担 sticky，保持在导航下方，长目录局部滚动。
- 手机目录选择后收起；锚点尊重减少动态效果偏好。
- Wouter 路由切换等待懒加载页面挂载，再恢复返回位置；用户手动滚动会中止待完成的恢复。
- 归档月份按服务端 UTC 分组显示，修复美国时区下 8 月显示成 7 月的问题；归档日标签同样使用 UTC。
- 为手机仅显示箭头的返回链接补充可访问名称。

- 首页渲染闸门：1440×900、1280×800、768×1024、390×844，浅色与深色，另含 320px 重排和减少动态效果；0 fail、77 pass。

- 脚本的同字体栈 WARN 已人工审阅：这是明确选定的单一无衬线体系，显示与正文通过字重、尺度和行距分工，不是未加载字体后静默使用框架默认字体。

自动闸门的部分首页截图在文章数据尚未加载完成时采集，因此该批自动截图主要证明首屏布局；真实文章、后续内容和操作使用等待数据就绪的内置浏览器及运行时测试补充验证。没有把加载占位视为文章列表验收通过。

**内置浏览器实际走查**：首页、算法分类、文章、搜索、归档、关于；首页中英文和深浅色，桌面及手机。检查了搜索 RoPE、菜单开关和跳转关闭、分类路径展开、手机目录选择并收起、桌面目录滚动、文章返回首页，以及主题／语言切换。部分菜单需要等待退出动画完成才能判断卸载，瞬间 DOM 仍存在不能当作关闭失败。

长程 Agent 样本有 4 个正常排版的数学区域，页面仅 1 个 H1；向下滚动 1000px 时桌面目录顶部为 100px。生产构建的自动往返测试，首页位置 707px → 文章 → 返回 707px，差值 0。运行时测试未捕获页面异常。减少动态效果时 canvas 数量为 0；模拟 WebGL context lost 后静态图 opacity 为 1。

**首次升级性能记录（光学重做前）**：本地生产构建、Playwright Chromium、1440×900、4 倍 CPU 限速，实际执行主题与语言两次交互，记录的最长交互事件为 48ms，出现一次 59ms 长任务。场景最终停稳。它是有限场景的实验室样本，不是线上 INP 或真实手机 GPU、续航、长期帧率的保证。

## 视觉对照记录

| 部位 | 基线 / 中间版本的问题 | 最终处理与观察 |
| --- | --- | --- |
| 构图 | 旧版三行分类名称与右侧目录争夺注意力 | 标题与星系明确分区，下方文章独立组织 |
| 字体 | 衬线显示与细小多栏正文比例失衡；第一稿通用粗体口号 | 个人站名、较轻显示字重、中文正文独立排版 |
| 星系 | 前版点精灵过小、亮星缺乏宽光晕；浅色点云像灰尘 | 独立恒星面片及星核 / 近晕 / 宽晕，补充中心星群和冷暖颜色；两主题保留深空主视觉 |
| 背景 | 旧阅读页保留黑色渐变块，搜索使用厚重框体 | 去掉残留渐变和重复框体，主题底色保持连续 |
| 信息密度 | 搜索与引导挤占首页；分类路径占据很长前导 | 保留导航搜索、单一阅读入口；分类路径可展开 |
| 移动端 | 搜索结果标题被全宽操作区挤压 | 标题弹性占宽、操作区按内容宽度；复查不再重叠 |
| 阅读 | 公式源文本、异常标题、目录滚走、返回位置丢失 | 真正排版、目录 sticky、返回恢复均以交互核验 |

旧版与最终版的 1440×900 截图使用内置浏览器保存并通过 view_image 对照检查；同时检查最终手机截图和减少动态效果截图。QA 图片和脚本均放在 `/tmp/misaya-*`，没有纳入项目源文件。

复查覆盖 1440×900 与 390×844 两主题、静态后备、无动画开关、离屏 / 静止状态及 context lost。首页选择相关测试 4 项通过；类型检查与构建通过。截图保存在 `/tmp/misaya-iab/optics-*`；正式素材仅为纯星系后备图。

本轮双主题渲染闸门最终为 0 fail、41 pass、4 个同字体体系人工评审提示。生产构建在 1440×900、4 倍 CPU 限速下复测两次交互，最长记录为 48ms，采样窗口内未记录到长任务；不将这个短样本视为线上 INP 或真实手机帧率保证。减少动态效果无 canvas、context lost 后后备可见、无页面异常均复查通过。最终桌面比较图通过项目 Playwright 在固定 1440×900 导出并检查，内置浏览器用于实际操作与视觉走查。
